# vibe-guard 新手使用说明

> 这份说明写给「用 AI 写程序、但没学过写程序」的你。装好之后，你照平常一样跟 AI 说话就行，vibe-guard 会在背后帮你把关。

## 它会帮你做什么

| 你会遇到的事 | vibe-guard 会怎么做 |
|---|---|
| 想法还很模糊 | AI 会先问你几个关键问题（给你建议，你可以只回「照你建议」），整理成一页需求 |
| AI 要改代码 | 大一点的改动，AI 会先用白话告诉你打算怎么做，等你点头 |
| AI 说「做好了」 | AI 必须告诉你它**实际试过什么、还没试过什么**，不能只说「应该可以了」 |
| 改坏了 | 可以退回之前能用的版本（见下面「改坏了怎么办」） |
| 一直修不好 | AI 修两次还没好，就会停下来换一种更有条理的方式找原因，不再乱猜 |
| 密钥（API key、数据库密码） | 如果 AI 要把密钥写进程序里，会被直接挡下来，改成安全的放法 |
| 危险操作（删数据、上线、强制覆盖） | 会先跳出确认，告诉你后果和更稳妥的做法，你同意才会执行 |
| 准备上线 | 会先做一次上线前检查；没检查就上线，会被提醒 |
| 上线后出事 | 网站打不开、账单暴涨、密钥外泄时，AI 会先帮你止血，再找原因 |

## 你可以这样跟 AI 说

不用记任何指令，用平常说话的方式就行：

- 「我想做一个 ___，帮我先把需求想清楚」
- 「帮我开始一个新项目」
- 「帮我加一个 ___ 功能」
- 「又坏了」「还是不行」「之前明明可以的」
- 「这个报错是什么意思？」（直接把报错贴上来）
- 「为什么要这样做？」「一定要吗？」「不做会怎样？」
- 「项目越来越乱了，帮我体检一下」
- 「我准备上线了」「怎么放到网上给别人用？」
- 「网站打不开了！」「账单突然好多钱！」

## 改坏了怎么办

- **Claude Code**：按两次 `Esc`（或输入 `/rewind`），选择要回到的那一步。注意：它只能还原 AI 改过的文件；像删除文件、安装东西这类操作，要请 AI 用 git 帮你找回
- **Codex**：直接说「回到上一个存档」。vibe-guard 会在 AI 每次停下时自动存一次档
- 两边都可以说：「回到上一个能用的版本」，AI 会从存档里找

## 我的项目怎么在自己电脑上跑起来

- **启动方式写在项目里的 `AGENTS.md`**（「怎么跑起来」那一节），AI 每做完一个功能都会更新它
- 忘了就直接问 AI：「这个项目怎么启动？」「我要怎么打开它看看？」
- 常见的样子是：打开「终端」→ 进到项目文件夹 → 输入一行命令（例如 `npm run dev` 或 `node server.js`）→ 用浏览器打开 AI 告诉你的网址（例如 `http://localhost:3000`）
- 终端窗口要一直开着，网页才打得开；用完按 `Ctrl + C` 关掉
- 打不开时，先确认终端里的程序还在跑，再把终端里的文字整段贴给 AI

## 确认框出现时

看到 `[vibe-guard]` 开头的确认，**先读完再按**。它会写：

- 📌 这条命令会做什么
- ❓ 为什么要先确认
- ✅ 更稳妥的做法

看不懂、不确定，就选「不」，然后问 AI：「这个是什么意思？有没有更安全的做法？」

## 三件你一定要自己做的事

AI 没办法替你登录各个服务的后台，这三件要你自己动手（AI 会一步一步教你）：

1. **设预算上限**：每个会花钱的服务（例如 OpenAI、云服务）都设「最多花多少」
2. **密钥不要贴进对话里**：需要填密钥时，AI 会告诉你填在哪个文件或哪个后台，不要贴给 AI
3. **上线前让 AI 做一次检查**：说「我准备上线了」就会开始

## 如果你其实是工程师

说一句「我是工程师，以后不用解释这么多」，vibe-guard 会切换成资深模式：检查和拦截照样做，但不再做教学性的说明。想切回来就说「我看不懂，讲详细一点」。

## 遇到问题

- 觉得 AI 太啰嗦，或者看不懂它在说什么 → 直接告诉它
- 确认框太频繁、挡住了正常的操作 → 记下当时在做什么，告诉帮你装 vibe-guard 的人
- 怀疑密钥已经外泄 → 说「我的密钥可能泄露了」，AI 会带你处理
