# 试跑记录 2026-09-21

- 平台：Claude Code（`claude -p`，模型 sonnet），vibe-guard 0.6.0，新手模式
- 项目：从空文件夹开始的「个人记账网页」（Node.js 自带模块 + 原生 HTML/JS）
- 方式：每个阶段开新对话（阶段内的追问用 `--continue`），用 stream-json 记录实际调用的 skill 与执行的命令
- 限制：非交互模式下，未在允许清单里的命令会被直接拒绝（真实使用时会弹确认）；AI 没有浏览器工具，网页 UI 未实际点过

## 发现并已修复

1. **报错解释没触发 explain-plain**：用户贴报错原文问「什么意思」时，AI 直接回答。修复：description 写明「贴出报错原文（Error、TypeError、Uncaught…）时先用本技能」，session 技能清单同步注明。重测通过
2. **需求访谈推荐「存成本机文件」时没在第一轮讲出代价**（要另外一直跑后台小程序）。第二轮写 SPEC 时有讲，但太晚。修复：question-bank 增加这一题并要求第一轮讲出代价，同时修正「要记住就用在线数据库」与后续建议矛盾的一行。重测后第一轮推荐浏览器存储 + 导出备份，并讲清存文件的代价

## 观察（未修改）

- small-steps 规定「验证通过就存档」，AI 实际是等用户亲手试过才存档。比规定更谨慎，保留
- AI 提交用户项目时会带上 Co-Authored-By 行（Claude Code 的默认行为），新手可能不理解，试点时观察是否造成困惑
- 阶段 9 未触发 incident-rescue 属于合理判断（没有上线就没有事故）
