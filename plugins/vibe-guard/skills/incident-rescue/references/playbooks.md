# 各类事故的处理手册

> 各服务后台的菜单位置会变。以下是**要做什么**；找不到时请用户截图，照着截图指路。

---

## A. 网站打不开 / 大面积报错

### 止血
1. **最近上过新版本 → 先回滚**，不要先修。用 AGENTS.md「上线与回滚」里记的方法（或 `.vibe-guard/deploy.json` 的 rollback），把正式网站退回上一个正常的版本。回滚后用 `deploy-guide/scripts/smoke_test.py` 确认恢复
2. 没上过新版本，按顺序排查：
   - 托管平台、数据库服务本身是否故障：看对方的状态页（status page）
   - 域名是否过期、HTTPS 证书是否失效
   - 免费额度是否用完（很多平台额度用完会直接停服）
   - 环境变量是否被改过或删掉
   - 数据库是否连不上（连接数满、被暂停 —— 部分免费数据库闲置一段时间会自动暂停）

### 修复
回滚后在本机或预览环境重现问题，按 debug-rescue 找原因，修好走 ship-check 再上线。

---

## B. 账单暴涨 / 被盗刷

### 止血（按顺序，越快越好）
1. **在服务后台把额度上限调到很低，或直接暂停相关服务 / 项目**
2. 看用量图，找出是哪个服务、哪个密钥、从什么时候开始暴涨
3. 用量来源可疑（不是自己的网站在用）→ 当作密钥外泄，跳到 **C** 作废密钥
4. 是自己的网站在用（例如被人疯狂调用你的 AI 功能）→ 临时关掉该功能，跳到 **E** 加限制

### 修复
- 所有调用付费 API 的地方都经过后端，并加「每个用户每天 N 次」「整体每天 N 次」的上限
- 确认预算告警和硬上限都设好了（safe-start 的 budget-alerts）
- 检查有没有代码在循环或每次页面刷新时重复调用付费 API

### 争取退款
很多服务对「被盗用」有申诉渠道。帮用户整理：发生时间、异常用量截图、已作废密钥的证明、已采取的防护措施，去对方的客服或支持页面申诉。**不要承诺一定能退**。

---

## C. 密钥外泄

包括：推到了公开 GitHub、写进了前端代码、贴到了聊天或截图里、收到 GitHub / 服务商的泄露警告邮件。

### 止血
1. **立刻作废这个密钥并生成新的** —— 步骤见 `key-rotation.md`。这是唯一真正有效的动作；从代码里删掉、改 git 历史都不能让已经被拿走的密钥失效
2. 新密钥只放进 `.env`（本机）和托管平台的环境变量（线上），然后重新部署
3. 查这个密钥在外泄期间的使用记录：有没有不是你发起的调用？有 → 同时按 **B** 处理

### 修复
- 找出密钥是怎么流出去的，堵住那条路（vibe-guard 的密钥拦截通常能挡住「写进代码」这一类）
- 清理 git 历史是次要的，而且有风险（改写历史会影响所有人的副本）；密钥已经作废后，旧密钥留在历史里也无法再用

---

## D. 数据被看光 / 被改 / 被删

### 止血
1. **先堵住入口**：
   - 数据库权限规则写错（例如 Supabase 规则写成 `using (true)`、Firebase 规则开放）→ 立刻改成最严格的规则，功能暂时坏掉也比继续外泄好
   - 最高权限密钥（Supabase service_role、Firebase Admin 密钥等）可能外泄 → 按 **C** 作废
   - 必要时暂时下线网站
2. **不要急着恢复备份覆盖现场**：先把当前状态导出一份留证，再决定怎么恢复

### 恢复数据
- 从备份恢复时，**先恢复到一个新的数据库 / project 里**，确认数据正确，再切换或把缺的数据导回去 —— 直接覆盖正式数据库，万一备份也有问题就全没了
- 没有备份：如实告诉用户，能找回多少就找回多少（例如从日志、从用户那边重新收集），并在复盘里把「开自动备份并演练恢复」列为第一条

### 要不要通知受影响的人
涉及个人信息（名字、电话、邮箱、地址、身份证、照片等）外泄时，很多地方的法律**要求通知**受影响的人，甚至通知监管机构，例如：
- 中国大陆：《个人信息保护法》规定发生或可能发生个人信息泄露时，应立即采取补救措施，并通知履行个人信息保护职责的部门和个人
- 欧盟用户：GDPR 通常要求在知悉后 72 小时内向监管机构报告

你不是律师 —— 把这些告诉用户，建议对方在规模较大或不确定时咨询专业人士，由用户决定怎么做。**不要建议隐瞒**。

## E. 被攻击 / 刷量 / 垃圾注册

### 止血
- 临时关闭注册，或要求邮箱验证
- 打开托管平台的防火墙 / 防机器人功能（很多平台有一键开启的攻击防护或速率限制）
- 被刷的是付费功能（AI 调用、发短信、发邮件）→ 先关掉这个功能，并按 **B** 检查费用

### 修复
- 后端对注册、登录、付费功能加速率限制（同一个 IP / 账号每分钟最多 N 次）
- 注册加人机验证（例如 Cloudflare Turnstile、hCaptcha）
- 清理垃圾账号前，先导出一份留证
