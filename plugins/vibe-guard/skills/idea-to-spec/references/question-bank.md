# 需求访谈题库

按「影响范围」由大到小排。前两组几乎每个项目都要问；后面的按项目类型挑。
每题的「默认建议」是用户答不出来时的兜底选择 —— 原则是**最简单、以后最好改**。

## A. 谁在用（决定架构）

| 问题 | 为什么重要 | 默认建议 |
|---|---|---|
| 只有你自己用，还是会给别人用？ | 给别人用 = 需要登录、权限、隐私保护、上线部署 | 先只给自己用 |
| 大概几个人用？10 个 / 1000 个 / 更多？ | 决定要不要考虑性能和费用 | 按 10 人内设计 |
| 在电脑上用还是手机上用？ | 决定做网页、手机 app 还是都要 | 做网页，手机浏览器也能打开 |

## B. 数据（最容易出事）

| 问题 | 为什么重要 | 默认建议 |
|---|---|---|
| 要记住哪些东西？关掉再打开还要在吗？ | 决定要不要存数据、存在哪 | 要记住 → 看下一题决定存在本机还是云端 |
| 换一台设备要能看到同样的数据吗？ | 本地存储 vs 云端数据库，后改很痛 | 要 → 云端；不要 → 浏览器本地存储 + 导出备份 |
| （只在一台电脑用时）要存成电脑上的一个文件吗？ | 网页不能直接写电脑上的文件，存成文件就要另外一直跑一个后台小程序，每次使用前要先在终端启动 | 不需要 → 浏览器本地存储 + 导出备份。推荐存文件时，**第一轮就要讲出「每次用之前要先启动小程序」这个代价** |
| 数据丢了能接受吗？ | 决定备份要求 | 不能接受，开自动备份 |
| 会存别人的个人信息吗（名字、电话、身份证、照片）？ | 涉及隐私和法规 | 尽量不存 |

## C. 账号

| 问题 | 为什么重要 | 默认建议 |
|---|---|---|
| 需要登录吗？ | 登录是新手最容易出安全问题的地方 | 只有自己用就不要登录 |
| 用什么登录？邮箱 / 手机号 / 微信 / Google？ | 手机号、微信要额外申请与费用 | 用现成服务的邮箱或 Google 登录，不要自己存密码 |
| 不同的人能看到的东西不一样吗？ | 需要权限设计 | 每个人只看得到自己的 |

## D. 钱

| 问题 | 为什么重要 | 默认建议 |
|---|---|---|
| 要收钱吗？ | 收款牵涉支付接入、退款、税务 | 第一版不收 |
| 每个月愿意花多少在服务器和 API 上？ | 决定选型，防止账单爆炸 | 0 元，只用免费额度，并设预算上限 |
| 会调用 AI 模型（ChatGPT / Claude）吗？ | 按次计费，被刷会很贵 | 调用必须经过后端，并设每日上限 |

## E. 外部连接

| 问题 | 为什么重要 | 默认建议 |
|---|---|---|
| 要连别的服务吗（地图、支付、邮件、表格、AI）？ | 每个都要申请密钥、都有费用和额度 | 第一版最多接一个 |
| 要发邮件 / 短信 / 推送通知吗？ | 需要第三方服务，容易被当垃圾信 | 第一版不做 |

## F. 成功标准

| 问题 | 为什么重要 | 默认建议 |
|---|---|---|
| 做到什么程度你会觉得「成了」？ | 防止范围无限膨胀 | 核心动作能顺利走通一遍 |
| 有没有参考的 app 或网站？ | 最快对齐想象 | — |
| 什么时候要用上？ | 决定要砍多少 | — |
